# Pixel Tic Tac Toe

A two-player Java 21 Swing game with a forest-and-clay, pixel-inspired theme.

## Requirements

- JDK 21
- Maven

## Build and run

Open a terminal in this project folder and build the JAR:

```bash
mvn clean package
```

Launch it with:

```bash
java -jar target/tic-tac-toe-1.0-SNAPSHOT.jar
```

Run the game-logic tests with `mvn test`.
