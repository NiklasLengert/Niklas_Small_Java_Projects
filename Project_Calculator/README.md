# Pixel Calculator

A Java 21 Swing calculator with a forest-and-clay, pixel-inspired theme.

## Requirements

- JDK 21
- Maven

## Build and run

Open a terminal in this project folder and build the JAR:

```bash
mvn clean package
```

Launch it with:

```bash
java -jar target/calculator-1.0-SNAPSHOT.jar
```

Run the unit tests with `mvn test`.
